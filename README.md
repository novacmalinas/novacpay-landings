# Посадочные страницы NovacPay (B2C) — China Business Forum

Статичные страницы, без сборки. Вся папка `chinabusinessforum/` копируется как есть
в корень сайта novacpay.pro, адреса получаются такие:

| Адрес | Метка бота |
|---|---|
| `/chinabusinessforum/` — все направления | `lp_hub` |
| `/chinabusinessforum/card/` | `lp_card`, `lp_card_premium`, `lp_card_online` |
| `/chinabusinessforum/invoice/` | `lp_invoice` |
| `/chinabusinessforum/partner/` | `lp_partner` |
| `/chinabusinessforum/referral/` | `lp_referral` |
| `/chinabusinessforum/team/` | `lp_team` |

Пока страницы на согласовании, они доступны через GitHub Pages этого репозитория
по тем же путям.

## Для согласования (Эдгар)

- На страницах «Все направления», «Карта» и «Пригласить друга» есть плашка
  «Только сегодня: выпуск без проверки паспорта». Скрипт показывает её только
  **23.11.2026 по Москве**. Маркетинг согласовал выпуск без проверки паспорта на
  один день, Эдгар в курсе. FAQ на `card/` («Да, при выпуске проходит быстрая
  проверка личности») описывает обычные дни и остаётся без изменений.
- В подвале указаны реквизиты с novacpay.pro: ОсОО «РСПлюс», ИНН 00809202310438
  (Кыргызская Республика), ссылки на оферту и политику конфиденциальности.
- В `<head>` стоит `<meta name="robots" content="noindex">`. После подтверждения
  Эдгара эту строку убираем со всех страниц.

## Откат

Удалить папку `chinabusinessforum/` с сервера или выключить GitHub Pages.
Бот при этом не ломается.
